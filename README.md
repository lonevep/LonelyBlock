# LonelyBlock
# 🚀 Minecraft 1.8-26.2 全版本 方块控制插件 🚀

## 插件功能
用户可以在配置文件中 **自定义采集方块/ 采集指定方块后的掉落物/ 采集后获得的金币(Vault)/点券(PlayerPoints)/经验/自定义变量**

可以设定**指定的采集工具**
并且可以自定义**挖掘所需时间、使用指定采集工具后减少的挖掘时间/挖掘掉落倍率**

## 插件特色

插件完全适配 **1.8~26.3全版本** 并呈现出良好的适配性

插件配置文件的注释讲解 以及插件开源代码中的注释讲解 **极度完善**

插件具有高度<ins>**自定义性**</ins>

- 自定义发送消息

- 自定义获取变量

- 自定义lore识别

- 自定义采集工具

- 自定义挖掘方块各项指标

- 自动化服务:
-  自动查表设置方块硬度
-  自动计算急迫和挖掘疲劳的效果 最终呈现出一个较为准确的挖掘所需时间

同时 该插件适配两大流行物品库 **MythicMobs物品库** 和 **NeigeItems物品库** 所有物品的获取均基于这两个物品库

**MythicMobs物品库:** https://mythiccraft.io/index.php?resources/mythicmobs.1/

**NeigeItems物品库:** https://github.com/ankhorg/NeigeItems-Kotlin/releases
